# KIDDO Mini App — интерактивный прототип

Откройте `index.html` в браузере на компьютере или телефоне. Интерфейс работает без сервера и без установки зависимостей.

Что можно проверить: переключение экранов, отправку заданий на проверку, подтверждение родителем, начисление звёзд, автоматическое накопление, ручное пополнение копилки, премии и награды.

Данные сохраняются **только в браузере** (localStorage). Это демонстрационные данные, не настоящая база семьи. Сброс: очистить данные сайта в браузере.

**Не подключено:** Telegram авторизация, сервер, существующая SQLite-база KIDDO, платежи, семейные аккаунты, настоящие уведомления и защита ролей. Переключатель «Родитель / Ребёнок» создан для демонстрации, а не для контроля доступа.

Для публикации как Telegram Mini App потребуется HTTPS-хостинг, безопасная проверка Telegram initData на сервере, API и миграция данных из текущего бота.
